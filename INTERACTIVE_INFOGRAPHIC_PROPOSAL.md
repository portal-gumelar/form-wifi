# 🎨 PROPOSAL DESAIN: LANDING PAGE INFOGRAFIS INTERAKTIF
## Visualisasi Sistem Autopilot ARMEDIA Net (Coolify, Supabase, n8n, & MikroTik)

## 1. KONSEP DESAIN & AESTHETIC GUIDELINES
Agar arsitektur jaringan yang rumit (database, server, router) dapat dipahami secara instan dalam 3 detik oleh siapa pun, landing page infografis wajib didesain dengan konsep **"Premium Tech-Forward & Clean Minimalist"**.

### 🎨 Sistem Warna (Branding Harmony)
* **Warna Latar (Deep Space Navy)**: `#0D1655` (Memberikan kesan kokoh, aman, dan berteknologi tinggi).
* **Warna Aksen 1 (Vibrant Orange)**: `#F47920` (Menggambarkan kecepatan, konektivitas, dan energi ARMEDIA).
* **Warna Aksen 2 (Amber Gold)**: `#FDB913` (Menyatakan kemewahan, nilai premium, dan status aktif).
* **Card Background (Glassmorphism)**: `rgba(255, 255, 255, 0.03)` dengan filter `backdrop-blur-lg` dan border tipis putih `rgba(255, 255, 255, 0.1)`.

## 2. TATA LETAK LAYOUT: BENTO GRID INTERAKTIF
Menggunakan tata letak **Bento Grid** (kotak-kotak modular modern yang dipopulerkan oleh Apple & Microsoft) untuk mengelompokkan setiap tahapan alur sistem secara rapi.

```text
+-----------------------------------------------------------+
|                    HEADER BRANDING                        |
|        "Sistem Otomasi Pendaftaran & Billing Autopilot"   |
+-----------------------------+-----------------------------+
|                             |                             |
|      1. USER REGISTRATION   |      2. n8n AUTOMATION      |
|      (Pendaftaran & KTP)    |      (Otak Otomasi)         |
|                             |                             |
+-----------------------------+-----------------------------+
|                             |                             |
|      3. DATABASE STORAGE    |      4. MIKROTIK CONTROL    |
|      (Supabase Cloud)       |      (PPPoE & Isolir)       |
|                             |                             |
+-----------------------------+-----------------------------+
```

### 📦 Penjelasan Detail Setiap Box Bento Grid:

#### 👤 Box 1: Pendaftaran & Input Data (Pemicu Awal)
* **Visual**: Ilustrasi handphone modern 3D memuat form pendaftaran mini.
* **Elemen Interaktif**: Saat kursor diarahkan (*hover*), muncul animasi garis berkilau (*glowing laser line*) yang mengalir keluar menuju Box 2.
* **Teks Keterangan**: *"Pelanggan mengisi formulir pendaftaran sekali, otomatis menghitung tagihan pro-rata & mengunggah KTP secara instan."*

#### 🤖 Box 2: n8n Workflow Automation (Jantung Sistem)
* **Visual**: Maskot robot n8n beranimasi dinamis dengan roda gigi bercahaya yang berputar pelan.
* **Elemen Interaktif**: Ada 3 tombol pemicu virtual yang bisa diklik oleh user untuk mensimulasikan pengiriman pesan:
  * Tombol `Jadwal Survei` ➡️ Memunculkan miniatur pesan WhatsApp virtual terkirim.
  * Tombol `Instalasi` ➡️ Menampilkan ikon persetujuan etika penarikan kabel.
  * Tombol `Biaya Pro-rata` ➡️ Memunculkan kuitansi digital.
* **Teks Keterangan**: *"Robot n8n bekerja 24 jam non-stop menyalurkan data pendaftar ke tim lapangan dan mengirim pesan konfirmasi otomatis ke WhatsApp pelanggan."*

#### 💾 Box 3: Supabase PostgreSQL (Pusat Penyimpanan)
* **Visual**: Visualisasi tumpukan server bercahaya neon biru dan oranye dengan indikator database yang menyala berkedip (*blinking database nodes*).
* **Teks Keterangan**: *"Seluruh arsip data pelanggan dan foto KTP tersimpan aman secara terpusat di server cloud database Supabase yang super cepat."*

#### 🔌 Box 4: Kontrol Router MikroTik (Eksekusi Fisik)
* **Visual**: Router MikroTik 3D dengan lampu port LAN yang berkedip hijau.
* **Elemen Interaktif**: Toggle switch virtual **[AKTIF / ISOLIR]**.
  * Jika diklik ke **AKTIF** ➡️ Router menyala hijau terang, muncul teks *"Internet Lancar 20Mbps"*.
  * Jika diklik ke **ISOLIR** ➡️ Router menyala oranye/merah, memunculkan mockup layar HP terblokir *"Internet Terisolir - Silakan Lakukan Pembayaran"*.
* **Teks Keterangan**: *"Otomatisasi isolir PPPoE tanpa sentuhan tangan manusia. Pelanggan terlambat otomatis terisolir, begitu bayar instan menyala kembali."*

## 3. MICRO-ANIMATIONS & INTERACTIVE SIMULATOR (WOW FACTOR)
Fitur unggulan utama agar landing page ini sangat menarik dan mudah dipahami adalah **"Live Interactive Simulator Panel"** di bagian bawah halaman:

1. **Tombol Simulasi**: Terdapat tombol besar bertuliskan **"⚡ MULAI SIMULASI ALUR DAFTAR BARU"**.
2. **Animasi Berantai**: Begitu diklik, sebuah pulsa cahaya bersinar (*glowing pulse*) akan berjalan melintasi jalur kabel virtual di layar:
   * **Tahap 1**: Pulsa bergerak dari form registrasi ➡️ mengeluarkan suara ketikan halus.
   * **Tahap 2**: Pulsa masuk ke ikon n8n ➡️ robot berputar & ikon WhatsApp berkedip menyala.
   * **Tahap 3**: Pulsa bercabang ➡️ satu masuk ke server Supabase (lampu database berkedip), satu masuk ke MikroTik (port menyala hijau terang).
3. **Efek Edukasi**: Pengguna atau investor yang melihat langsung mengerti alur sistem ARMEDIA Net tanpa perlu membaca dokumen teknis berlembar-lembar!
