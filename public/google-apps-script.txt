====================================================
PANDUAN: KONEKSI FORM KE GOOGLE SHEETS
====================================================

1. Buka Google Spreadsheet Anda:
   https://docs.google.com/spreadsheets/d/13RcF4n9qu1b4hjlDw09wTDUT7JHoxnr7lxXOJxd_Rq4/edit

2. Buat baris header di Sheet1 (baris pertama):
   Kolom A: Timestamp
   Kolom B: Provider Saat Ini
   Kolom C: Nama Lengkap
   Kolom D: Kecamatan
   Kolom E: Desa
   Kolom F: Alamat Pemasangan
   Kolom G: No HP / WA
   Kolom H: Paket
   Kolom I: Tanggal Rencana Pasang
   Kolom J: Bisa Google Maps
   Kolom K: Link Google Maps
   Kolom L: Waktu Survei
   Kolom M: Prioritas
   Kolom N: Sumber Info

3. Buka Apps Script:
   Klik menu Extensions → Apps Script

4. Hapus kode yang ada, lalu tempel kode ini:

----------------------------------------------------
const sheetName = 'Sheet1'
const scriptProp = PropertiesService.getScriptProperties()

function initialSetup() {
  const activeSpreadsheet = SpreadsheetApp.getActiveSpreadsheet()
  scriptProp.setProperty('key', activeSpreadsheet.getId())
}

function doPost(e) {
  const lock = LockService.getScriptLock()
  lock.tryLock(10000)

  try {
    const doc = SpreadsheetApp.openById(scriptProp.getProperty('key'))
    const sheet = doc.getSheetByName(sheetName)

    const headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0]
    const nextRow = sheet.getLastRow() + 1

    const newRow = headers.map(function(header) {
      return e.parameter[header] || ''
    })

    sheet.getRange(nextRow, 1, 1, newRow.length).setValues([newRow])

    return ContentService
      .createTextOutput(JSON.stringify({ 'result': 'success', 'row': nextRow }))
      .setMimeType(ContentService.MimeType.JSON)

  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ 'result': 'error', 'error': err.toString() }))
      .setMimeType(ContentService.MimeType.JSON)

  } finally {
    lock.releaseLock()
  }
}
----------------------------------------------------

5. Simpan dengan Ctrl+S

6. Jalankan fungsi initialSetup:
   - Klik dropdown di atas (pilih "initialSetup")
   - Klik tombol Run ▶
   - Izinkan akses jika diminta

7. Deploy sebagai Web App:
   - Klik tombol Deploy → New deployment
   - Pilih type: Web app
   - Execute as: Me
   - Who has access: Anyone
   - Klik Deploy
   - COPY URL yang diberikan (berakhiran /exec)

8. Tempel URL tersebut ke dalam file src/App.tsx:
   Cari baris: const GOOGLE_SCRIPT_URL = "..."
   Ganti dengan URL yang baru Anda copy
