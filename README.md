# 🌐 ARMEDIA.ID Registration Portal

A premium, modern customer registration system and administrative dashboard for **PT. Akses Artha Media (ARMEDIA.ID)**. Built with high-performance technologies to provide a seamless user experience.

---

## 🚀 Features

- **Professional Registration Flow**: Multi-step registration form with real-time validation.
- **Admin Dashboard**: Comprehensive management system to track registrations, view analytics, and manage customer status.
- **Bento-style UI**: Clean, modern interface designed for both desktop and mobile.
- **Google Sheets Integration**: Automated data synchronization via Google Apps Script (GAS).
- **Interactive Charts**: Visual data representation using Recharts.
- **Export Capabilities**: Export data to PDF and Excel formats.

## 🛠 Tech Stack

- **Frontend**: [React 19](https://reactjs.org/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Automation**: Python, Google Apps Script

## 🛠 Setup & Development

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/[username]/armedia-id-registration-form.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### Deployment
Build the production bundle:
```bash
npm run build
```
